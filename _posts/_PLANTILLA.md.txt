PLANTILLA DE ARTÍCULO
=====================

Cómo publicar uno nuevo:

  1. Copia este archivo a  _posts/AAAA-MM-DD-titulo-en-minusculas-con-guiones.md
     El nombre del archivo determina la fecha y la URL. Es obligatorio ese formato.
  2. Rellena el front matter y escribe en Markdown normal.
  3. git add . && git commit && git push
     GitHub genera el HTML solo. No hay que compilar nada en local.

La URL resultante será  /research/titulo-en-minusculas-con-guiones/

DOS COSAS QUE NO PUEDES SALTARTE
--------------------------------

  · El bloque  toc:  del front matter. Es lo que dibuja el índice numerado de la
    cabecera. Si no está, el artículo sale sin índice.
  · El ancla  {#id}  al final de cada encabezado. Los  id  del  toc:  tienen que
    coincidir exactamente con esas anclas o los enlaces del índice no van a
    ningún sitio. Sin tildes, sin mayúsculas, sin espacios.

Las tablas NO necesitan envoltorio de ningún tipo: el CSS ya les pone scroll
horizontal en pantallas estrechas.
